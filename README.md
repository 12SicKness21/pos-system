# 🏪 Sistema POS - Point of Sale

Sistema de punto de venta moderno y responsive construido con HTML, CSS y JavaScript vanilla.

## ✨ Características

- 💰 **Gestión de Ventas** - Carrito de compras intuitivo
- 👨‍💼 **Administración de Clientes** - Control de clientes y créditos
- 📦 **Inventario de Productos** - Gestión completa de productos
- 📈 **Reportes y Estadísticas** - Análisis de ventas
- 📷 **Escáner de Códigos** - Soporte para códigos de barras
- 🌓 **Tema Claro/Oscuro** - Interfaz adaptable
- 📱 **Mobile First** - Optimizado para dispositivos móviles
- 💾 **Almacenamiento Local** - Datos guardados en el navegador

## 🚀 Uso

Simplemente abre `index.html` en tu navegador o visita el sitio desplegado.

## 💱 Moneda

El sistema está configurado para usar **Sol Peruano (S/.)**

## 🛠️ Tecnologías

- HTML5
- CSS3 (Vanilla CSS con variables CSS)
- JavaScript (ES6+)
- LocalStorage API
- Html5-QRCode para escaneo
